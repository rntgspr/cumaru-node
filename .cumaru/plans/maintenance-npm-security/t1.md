# T1 — Configure trusted publishers for the five packages

## What to do

Add a GitHub Actions trusted publisher to each `@cumaru/*` package.

## Context

All five packages exist since `0.15.1`. Trusted publishing config is a sensitive action, so it
needs interactive 2FA. Owner: Renato.

| Field | Value |
|---|---|
| Publisher | GitHub Actions |
| Organization or user | `rntgspr` |
| Repository | `cumaru-node` |
| Workflow filename | `publish.yml` |
| Environment | empty |

Packages: `@cumaru/cumaru`, `@cumaru/cli-darwin-arm64`, `@cumaru/cli-darwin-x64`,
`@cumaru/cli-linux-arm64`, `@cumaru/cli-linux-x64`.

## Implementation

1. Read [docs.npmjs.com/trusted-publishers](https://docs.npmjs.com/trusted-publishers) for the
   current UI and the bulk option announced on
   [2026-02-18](https://github.blog/changelog/2026-02-18-npm-bulk-trusted-publishing-config-and-script-security-now-generally-available/).
2. For each package: npmjs.com, package **Settings**, **Trusted publishing**, add the values above.
3. Optional: set **Publishing access** to require 2FA and disallow tokens.
4. Inspect `@cumaru/cli-linux-x64@0.0.0-stage` and record what it is.

## Done when

- [ ] Each package settings page lists `rntgspr/cumaru-node` / `publish.yml`.
- [ ] The origin of `0.0.0-stage` is recorded in the handoff.
