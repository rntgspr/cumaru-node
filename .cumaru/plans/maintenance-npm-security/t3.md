# T3 — Delete NPM_TOKEN and revoke the token

## What to do

Remove the 2FA-bypass token from GitHub and revoke it on npm.

## Context

The token `cumaru-node-ci` was created on 2026-11-17 for the first `0.15.1` publish. After T2 no
workflow reads it. Deleting a token is a sensitive action and needs interactive 2FA.

## Implementation

1. `gh secret delete NPM_TOKEN -R rntgspr/cumaru-node`.
2. On npmjs.com, **Access Tokens**, delete `cumaru-node-ci`.

## Done when

- [ ] `gh secret list -R rntgspr/cumaru-node` does not list `NPM_TOKEN`.
- [ ] The npm token list does not show `cumaru-node-ci`.
