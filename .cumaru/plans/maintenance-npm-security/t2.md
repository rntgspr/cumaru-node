# T2 — Switch publish.yml to OIDC only

## What to do

Remove the token from `publish.yml` and publish through OIDC.

## Context

`publish.yml` already has `id-token: write`, `registry-url`, and `--provenance`. The only token
use is `NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}` in the "Publish packages" step.

## Implementation

1. Remove the `NODE_AUTH_TOKEN` env from the publish step.
2. Add a step `npm install --global npm@<minimum from docs>` and print `npm --version`.
3. Keep `--provenance` (with trusted publishing npm adds provenance automatically; the flag is harmless).
4. Update the README release section: publishing uses trusted publishing, no token.
5. Prove it: publish the next upstream version through the normal dispatch, or re-run with a
   new version. Never republish an existing version.

## Done when

- [ ] `actionlint` passes and `publish.yml` contains no `NPM_TOKEN`.
- [ ] A publish run succeeds with no npm token present in the repository secrets.
- [ ] `npm view @cumaru/cumaru@<new> --json` shows provenance from `rntgspr/cumaru-node`.
