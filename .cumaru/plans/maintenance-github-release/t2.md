# T2 — CI workflow on main

## What to do

Add `.github/workflows/ci.yml` for `push` to `main` and `pull_request`. It
verifies the wrapper and never publishes.

## Context

The latest upstream version comes from `gh release view -R rntgspr/cumaru --json tagName`.

## Implementation

1. Resolve the latest upstream version.
2. Run `node scripts/assemble.mjs "$VERSION"`.
3. Run `npm pack --dry-run` in each `npm/*` directory.
4. Install the linux-x64 and main tarballs into a temp project and assert `node_modules/.bin/cumaru --version` equals `cumaru $VERSION`.
5. Assert a forwarded non-zero exit code (`cumaru nope` exits 2).

## Done when

- [ ] The CI run on the T1 push is green.
- [ ] A deliberate launcher break makes CI red (checked once on a branch).
