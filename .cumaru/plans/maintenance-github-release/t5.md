# T5 — Dispatch step in rntgspr/cumaru release

## What to do

Add a final step to the upstream `publish` job in
`../cumaru/.github/workflows/release.yml` that dispatches `cumaru-release` to
`rntgspr/cumaru-node` after `gh release edit --latest`.

## Context

The upstream job publishes the four binaries, `LICENSE`, and `SHA256SUMS`, then
marks the release latest. Cross-repository dispatch needs secret
`CUMARU_NODE_DISPATCH_TOKEN`: a fine-grained PAT limited to
`rntgspr/cumaru-node` with `contents: write`.

## Implementation

1. Create the PAT and store it as an upstream repository secret.
2. Add the step:

   ```yaml
   - name: Notify npm wrapper
     env:
       GH_TOKEN: ${{ secrets.CUMARU_NODE_DISPATCH_TOKEN }}
     run: gh api repos/rntgspr/cumaru-node/dispatches -f event_type=cumaru-release -F "client_payload[version]=$RELEASE_VERSION"
   ```

3. Commit in `../cumaru` on its own branch; follow that repository's flow.

## Done when

- [ ] The next upstream release run shows the dispatch step green.
- [ ] `rntgspr/cumaru-node` shows a matching release and npm shows the version.
