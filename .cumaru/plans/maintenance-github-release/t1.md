# T1 — Create rntgspr/cumaru-node and push main

## What to do

Create the public repository, repoint `origin`, fix `repository` fields, and
push `main`.

## Context

`origin` is `git@github.com:rntgspr/cumaru.git` today. The local history is one
squashed commit. The manifest `repository` field drives npm provenance.

## Implementation

1. `gh repo create rntgspr/cumaru-node --public --description "Node.js wrapper for the Cumaru CLI"` (outward action; confirm first).
2. `git remote set-url origin git@github.com:rntgspr/cumaru-node.git`; verify with `git remote -v`.
3. Set `repository` to `github:rntgspr/cumaru-node` and `homepage` to the repository URL in `package.json`; the assemble script copies both into every manifest.
4. Commit the wrapper work, then `git push -u origin main`.
5. Protect `main` against force-push.

## Done when

- [ ] `gh repo view rntgspr/cumaru-node` succeeds and `origin` points to it.
- [ ] `node scripts/assemble.mjs 0.15.1` writes `repository: github:rntgspr/cumaru-node` in all five manifests.
- [ ] `git ls-remote origin main` equals local `main`.
