# T6 — npm trusted publishers and first release

## What to do

Publish `0.15.1` once, then configure npm trusted publishing for all five
packages and remove the token.

## Context

Trusted publishers attach to existing packages. `@cumaru/cumaru` exists
(`0.0.8`); the four `@cumaru/cli-*` packages do not.

## Implementation

1. Add an npm automation token as `NPM_TOKEN` in `rntgspr/cumaru-node`.
2. Create GitHub Release `0.15.1`; confirm `publish.yml` publishes all five packages.
3. On npmjs.com, add a trusted publisher per package: repository `rntgspr/cumaru-node`, workflow `publish.yml`.
4. Delete `NPM_TOKEN`; the next release must publish through OIDC only.
5. Verify `npm view @cumaru/cumaru@0.15.1 optionalDependencies` and a clean `npx @cumaru/cumaru@0.15.1 --version` on macOS and Linux.

## Done when

- [ ] `npm view @cumaru/cumaru version` prints `0.15.1`.
- [ ] Each package page shows provenance from `rntgspr/cumaru-node`.
- [ ] `NPM_TOKEN` is removed.
