# T2 — Assemble script for platform packages

## What to do

Create `scripts/assemble.mjs <version>`. It downloads the release binaries and
`SHA256SUMS`, verifies checksums, and writes publishable packages to `npm/`.

## Context

Assets live at
`https://github.com/rntgspr/cumaru/releases/download/<version>/<asset>`.
The platform map lives once in `package.json` `optionalDependencies` plus a
target table in the script; `bin/cumaru.js` keeps its own host-to-package map.

## Implementation

1. Validate `<version>` as `X.Y.Z`.
2. Download `SHA256SUMS`, then each binary; compare SHA-256; abort on mismatch.
3. Write `npm/cli-<os>-<arch>/{package.json,cumaru,LICENSE,README.md}` with mode `0755` on the binary.
4. Write `npm/cumaru/` with the main manifest at `<version>`, pinned optional dependencies, `bin/`, `README.md`, `LICENSE`.
5. Ignore `npm/` in Git.

## Done when

- [ ] `node scripts/assemble.mjs 0.15.1` produces five package directories.
- [ ] `npm pack --dry-run` succeeds in each directory.
- [ ] The launcher runs the assembled host binary and prints `cumaru 0.15.1`.
- [ ] A tampered checksum makes the script exit non-zero.
