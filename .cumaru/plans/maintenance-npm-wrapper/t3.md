# T3 — GitHub Actions publish workflow

## What to do

Create `.github/workflows/publish.yml`. It assembles the packages for one
upstream version and publishes them to npm with provenance.

## Context

Triggers: `workflow_dispatch` with a `version` input, and `repository_dispatch`
type `cumaru-release` with `client_payload.version`, so the upstream release
workflow can call it later. Authentication prefers npm trusted publishing
(OIDC, `id-token: write`); `NPM_TOKEN` is the fallback.

## Implementation

1. Checkout, setup Node with the npm registry.
2. Run `node scripts/assemble.mjs "$VERSION"`.
3. Smoke-test the linux-x64 package through the launcher.
4. Publish `npm/cli-*` first, then `npm/cumaru`, each with `--provenance --access public`; skip a package whose version already exists.

## Done when

- [ ] The workflow YAML parses.
- [ ] Every step uses only the files from T1 and T2.
